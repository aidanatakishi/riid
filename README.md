# Rəqəmsal İdarəetmə Paneli (RİİD)

Jira dashboard — task, sprint, çətinlik və qiymətləndirmə analitikasını göstərir.

## Yükləmək

GitHub-un yaşıl **Code → Download ZIP** Windows-da bəzən yarımçıq (invalid) düşür. Tam arxivi **Releases**-dən götürün:

**[riid-main.zip — Releases](https://github.com/aidanatakishi/riid/releases/latest)**

Ölçü təxminən 300+ KB olmalıdır. ~40 KB-lik faylı açmayın.

Git ilə:

```
git clone https://github.com/aidanatakishi/riid.git
```

## İşə salmaq

1. Python 3 quraşdırın (`Add python.exe to PATH`).
2. `run.bat` — http://127.0.0.1:5000
3. İlk girişdə öz Jira tokeninizi (PAT) yazın. Token Git-ə düşmür.
